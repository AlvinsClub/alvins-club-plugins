# Alvin's Club plugins

Plugin bundles for the Claude directory. Each folder holds one plugin: manifest, README, license, icon, the remote
MCP connector URL and skills. No service code lives here.

- `brandpilot/`: BrandPilot, social media content planning for a person or a brand.
- `channel/`: Alvin's Club Channel, analyze results, draft captions and publish with approval.
- `seo/`: SEO & GEO by Alvin's Club, SEO audit and AI visibility for your website.
