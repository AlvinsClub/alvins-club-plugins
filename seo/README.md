# SEO & GEO by Alvin's Club

Check how your website shows up in Google Search and AI answers, right in Claude. Start by saying: "Check my
website's SEO and AI visibility." Nothing is edited or published from the chat.

## What is in this plugin

- `.mcp.json`: the remote SEO & GEO connector, https://studio.alvinsclub.ai/seo/mcp (OAuth sign-in on
  studio.alvinsclub.ai; you can connect first and add your email later).
- `skills/get-started`: how Claude runs a site check and reads Search Console reports, keyword opportunities and
  page audits for websites you own or manage.

It contains Markdown instructions and JSON configuration only: no local executables, hooks, install scripts or
package launchers, and no credentials.

## Data it sends

Tool calls send what the request needs to the SEO & GEO hosted service: the website address you ask it to check,
and for websites you connect on the SEO workspace, report and page-audit requests. Search Console is connected on
the website, never in chat. Checks cover sites the user owns or manages.
